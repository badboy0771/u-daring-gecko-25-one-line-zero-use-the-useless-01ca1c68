# One Line, Zero Use: The Useless Superpower Sprint

One original line, 140 characters, naming a hilariously useless superpower: the gift of teleportation, limited to three inches to the left — enough to ruin a prison break, not enough to escape one. The joke pays off in the last few words, when the great escape ends at the gift shop, buying a snow globe.

> I can teleport anywhere on Earth — but only three inches to the left, so my daring prison break ended at the gift shop, buying a snow globe.

## How to run

```sh
node main.ts
```

This writes the line to `/output/entry.txt`.
